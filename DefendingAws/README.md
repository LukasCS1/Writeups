## Writeup Structure
- **Room Overview** — Scenario context and misconfiguration summary
- **Category** — Room classification
- **Incident Summary** — Real-world scenario and impact
- **Core Failure** — The misconfiguration at the root of the incident
- **Identification Process** — How the misconfiguration was found — commands run, what they revealed
- **Remediation** — Steps taken to fix it — commands, policy changes, config adjustments
- **Secure Build** — Correct implementation from scratch
- **Tools & Environment** — Tools and environment context
- **Key Takeaways** — Attacker impact, correct control, relevant tooling
